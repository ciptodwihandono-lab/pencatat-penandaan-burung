Statistik Ringkasan

Ekspor / Impor / Backup

Ekspor Data

Unduh seluruh data sebagai file CSV (bisa dibuka di Excel) untuk backup atau analisis lanjutan.

Ekspor Peta (GPS)

Ekspor catatan yang punya koordinat GPS ke format peta, untuk dibuka di Google Earth atau aplikasi GPS/UTM seperti UTM Geo Map.

Impor

Muat data dari file CSV (format sama seperti hasil ekspor). Data akan ditambahkan sebagai catatan baru.

Ekspor / Impor Log Banding (Mist Net)

Data Log Banding tersimpan terpisah dari data tally sheet di atas — ekspor/impor CSV-nya juga terpisah.

Backup ke Folder Sinkron (Google Drive/OneDrive)

Pilih folder di komputer ini yang otomatis disinkronkan ke cloud (misalnya folder "Google Drive" dari Google Drive Desktop, atau folder OneDrive). Setiap backup akan menyimpan file CSV + JSON ke folder itu, lalu aplikasi sinkronisasi yang meng-upload-nya ke cloud.

Instal Aplikasi

Untuk bisa dipakai penuh secara offline, instal aplikasi ini ke perangkat Anda (ikon "Install app" pada browser, atau menu → "Add to Home Screen" di HP).
